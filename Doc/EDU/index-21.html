更新说明 - Easy Game UI v3.0¶

Easy Game UI 的 3.0 更新标志着一个激动人心的新篇章的开始！这次大规模免费更新为资源包的各个方面都带来了改进，目标有多个：让它更易用、性能更好、更加模块化，同时还加入了一些酷炫的新功能！
这次更新花了很长时间来构建，但今天终于可以完整地展示给你了，希望它能帮助你打造梦想中的游戏，而不用再为 UI 操心！¶

关于从旧版本升级的说明

为了改进该资源的所有系统并为未来做好准备，本次更新对其中大多数系统进行了重大的结构性调整。遗憾的是，这意味着如果你已经搭建过该资源的旧版本，就无法“直接替换”升级。
这个新版本需要对该资源进行完整的全新安装，如果你在过渡过程中需要帮助，欢迎随时联系我。

今后这一过程应该会大大简化，本次更新中的许多改动都是考虑到可升级性而做的，以便未来能够更顺畅地升级！

想亲自体验一下这次更新吗？来看看更新后的 Demo Build！

由于这次更新规模极其庞大，逐一深入讲解每一项改动会非常冗长，因此在这份更新日志中，我将概述这个新版本引入的大部分最重要的新增内容与改动！

这个新版本支持 Unreal Engine 5.3、5.4、5.5、5.6、5.7、5.8*
*初步测试是在 5.8 Preview 上进行的，未发现任何重大问题，完整测试有待正式版发布后进行

核心系统
  • 全新的 UI 导航系统
    本次更新带来了大幅改进的 UI 导航系统，它更强大、更易于实现，玩家体验也更流畅！过去必须为每个控件硬编码的大量逻辑，现在完全由系统自动处理，从而极大地简化了复杂控件堆栈的处理！
  • Code cleanup, bugfixing, simplification
    The entire codebase of the system has been cleaned up to fix many issues, bring signficant performance optimizations and be much easier to understand and expand.
    • 大多数系统也经过了重构，彼此之间更加独立，例如现在可以用副本或完全不同的控件来替换系统中的任意控件，这在修改现有系统的同时保留原始控件的完整副本时非常有用！
    • 新增了许多体验优化功能与改动，直接回应了大家在使用该资源时的反馈与困难！
    • 所有资源也都经过了清晰的重新整理与重命名，以更好地符合 UE 命名规范。
  • 更完善的主菜单流程
    开场流程（开场制作人员名单、按任意键界面）已从实际的主菜单中拆分出来，以便根据需求独立管理。我还添加了一种方法，可以用内置的模块化制作人员名单系统播放“开场制作人员名单”
  • 通用控件与全局样式改进
    所有通用控件都进行了多项改进，设置更简单，自定义更丰富。样式与配置（Styling & Config）也得到扩展和简化，新增了系统控件切换等功能，并对每个系统的控制更加精细
  • 惊艳的全新演示内容
    演示内容已更新，加入了惊艳的全新地图，以更好地展示该资源的功能。衷心感谢 FluidFury 的 Marco 制作了这些内容（去看看他超棒的游戏 Quantic River）！

关于本地化的说明

从本次更新开始，我做出了一个遗憾的决定：不再包含任何内置本地化。原因有多方面：UE 的本地化工具在最近几个版本中存在重大 bug、上传到 fab 的复杂性、制作本地化本身耗费大量时间，以及整体使用率有限。
尽管如此，选项菜单仍然内置了一套系统，如果你在游戏中实现了本地化，可以用它在不同本地化之间切换。

选项菜单
  • 全新的设置管理系统
    开发了一套全新的基于对象的系统，将每项设置集中到各自的“管理器”对象中，从而实现更加模块化的方式，并对设置的作用及作用方式拥有更大的控制权，且完全独立于选项菜单！这些改动极大地简化了选项菜单以及所有设置的处理！
  • 所有系统统一设置
    该资源的所有系统现在共享一套统一的设置系统，所有场景都使用同一组控件：选项菜单、拍照模式以及你需要的任何其他控件。结合管理器系统，可以毫不费力地设置能在多个系统中修改和访问的设置！
    这也让任何系统现在都能拥有以前只有选项菜单的设置控件与系统才支持的全部高级设置功能
  • 全新的按键重新绑定系统
    随着全面转向 5.3+，我有机会彻底重构按键重新绑定系统，加入了多项长期被请求的功能与改进。
    该系统现在支持 MNK 的次级映射槽位、应该展示给玩家但不可重新绑定的“锁定”按键、可支持跨 IMC 冲突的扩展冲突系统、输入修饰键的考量等等！
  • 借助全新的标签系统，大大简化了与设置关联操作的处理（例如根据另一项设置的值禁用某项设置），图形预设的处理也更加容易
  • 许多体验优化新增内容，例如更简单地移除/禁用设置、从选项菜单中移除标签页等等
存档系统
  • 扩展的存档能力
    该系统现在可以原生保存 Game Instance 变量以及 Actor Component 变量，并且可以通过新的蓝图接口轻松扩展到任何自定义的非 Actor 对象。系统现在还可以按需轻松保存你自己的存档对象。
  • 更好地支持世界分区与子关卡存档
    在游戏过程中因世界分区或子关卡而卸载的持久 Actor，现在也能被系统可靠地保存，无需任何额外工作！
  • 新增对存档“配置文件”的支持
    存档槽位现在可以归组到存档配置文件下，以支持多用户存档！该功能默认禁用，目前也没有与之关联的 UI，因为此类配置文件系统的实现方式会因游戏需求而有很大差异。
  • 存档调试工具
    全新的调试工具，可以直接在引擎内预览并轻松理解任何存档文件的内容。对于调试存档/读档问题非常有用！
  • 许多小型改进与体验优化改动
输入提示系统
  • 简化设置流程
    输入提示的所有可配置变量现在都放在两个专用结构中，分别用于样式和按键定义，从而使新旧所有功能的设置更简单，变量与逻辑更清晰
  • 扩展的“多输入提示”能力
    多输入提示（Multi Input Prompt）控件现在能够有效地显示彼此独立的按键，每个按键都有自己专用的参数。例如可以同时显示一个标记为“Hold”的动态键盘按键和一个标记为“Mash”的静态手柄按键，这在以前很难做到
  • 大量布局与性能改进
    系统进行了许多全局性改进，仅举几例：更快地查找与输入关联的按键、简化布局与材质的动画处理、更智能的设备切换检测逻辑，以及对按键刷新过程更精细的控制
拍照模式
  • 拍照模式处理的彻底重构
    该系统不再需要占据 Pawn，因此完全兼容多人游戏，并且 Actor 的管理也大大简化
  • 拍照模式的 UI 也得到了显著改进，独立性更强，在模式之间切换时输入/导航的整体管理也更加顺畅

以上就是对本次更新中最大改动的一次快速预览，总共有成千上万处改动，你在使用该资源时应该会感受到：设置流程更简化、任一功能的能力更强大，以及整体更好用的资源包！
如果你想了解任何具体的改动或这里没有列出的内容，欢迎联系我，我可以为你提供更多细节！
