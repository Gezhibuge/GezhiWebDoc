更新日志¶

V3.0.2 - 2026年6月18日

Easy Game UI v3.0.2¶

支持的版本：5.3 / 5.4 / 5.5 / 5.6 / 5.7 / 5.8

本次小幅更新带来了对 Unreal Engine 5.8 的正式支持，同时修复了 3.0 更新中存在的一些小问题：

  • 添加对 Unreal Engine 5.8 的支持
  • （5.8）修复了某些体积设置下可能发生的崩溃
  • 修复了禁用设置时出现的各种不一致行为
  • 修复了存档配置文件的若干问题
  • 修复了开场制作人员名单会显示一帧背景关卡的问题
  • 更新了设置导航逻辑，无需额外逻辑即可在任何地方使用
  • 修复了设置中各种轻微的视觉和音频问题
  • 清理了一些不再需要的逻辑

如果你想在不重新下载资源的情况下更新当前版本，请查看本升级指南

V3.0 - 2026年5月28日

Easy Game UI v3.0¶

支持的版本：5.3 / 5.4 / 5.5 / 5.6 / 5.7 / 5.8*
*初步测试已在 5.8 源码版上完成，未发现重大问题，完整测试尚待正式版发布

  • 重构了 UI 导航系统，使其更加通用，并简化了复杂控件栈的处理
  • 清理了整个代码库，修复遗留问题、优化性能，并按 UE 标准命名规范重新整理资源
  • 开发了全新的基于对象的设置管理系统，可对每项设置进行集中、模块化且独立的控制
  • 统一了设置架构，可在选项菜单、拍照模式和任意自定义控件中使用同一套精简设置
  • 重做了 UE 5.3+ 的按键重新绑定系统，新增次要槽位、锁定按键，并扩展了跨 IMC 冲突支持
  • 扩展了存档能力，可原生保存 Game Instance 变量、Actor Components 变量和自定义对象，同时改进对 World Partition、子关卡和多用户配置文件保存的支持。
  • 新增引擎内调试工具，可直接在编辑器中预览和调试存档文件内容
  • 为交互实现了多组件检测，可轻松管理单个 Actor 上的多个可交互部件（例如各个柜子抽屉）
  • 全面改造了输入提示系统，简化变量设置、加速底层逻辑，并新增更智能的设备切换检测
  • 扩展了多输入提示，可显示具有独立参数的独立按键（例如键盘“按住”配合手柄“连打”）
  • 改进了主菜单流程，拆分出专用的开场画面并支持开场制作人员名单
  • 升级了多个常用控件，并扩展了样式与配置选项，新增系统控件切换等功能，且对每个系统的控制更加精细
  • 彻底重做了拍照模式，不再需要占有 Pawn，简化了输入处理，并更好地分离控制器与 UI

完整更新说明 - Easy Game UI v3.0

V2.21 - 2025年11月13日

Easy Game UI v2.21¶

支持的版本：5.1 / 5.2 / 5.3 / 5.4 / 5.5 / 5.6 / 5.7

  • This update brings support for Unreal Engine 5.7 with several bugfixes related to that new version for the following issues:
    • 输入提示和按键重新绑定无法正常工作
    • “连打”输入无法正确重置
    • 图库中的“定位文件夹”按钮在编辑器中无法正常工作

如果你想将当前版本升级到 UE5.7，可以查看本指南：

UE5.7 升级指南

V2.2 - 2025年7月19日

Easy Game UI v2.2¶

支持的版本：5.1 / 5.2 / 5.3 / 5.4 / 5.5 / 5.6

  • 新增可随时完全禁用存档或读档系统的功能（可全局禁用，也可在游戏过程中选择性禁用）
  • 扩展了样式与配置选项，为多个系统新增设置
  • 对输入提示系统进行了多项改进，包括新的样式选项和优化
  • 对多个系统进行了全局代码清理和错误修复

更新说明 - Easy Game UI v2.2

V2.12 - 2025年6月3日

Easy Game UI v2.12¶

支持的版本：5.1 / 5.2 / 5.3 / 5.4 / 5.5 / 5.6

  • Added support for Unreal Engine 5.6 with several bugfixes related to that new version:
    • 修复了导致存档系统在游戏暂停期间无法正常工作的问题
    • 修复了导致演示按键绑定为空的问题
  • 修复了可能导致动态富文本无法正确显示重新绑定的按键的问题

如果你想将当前版本升级到 UE5.6，可以查看本指南：

UE5.6 升级指南

注意：UE5.5 中存在的截图问题已由 Epic 在 UE5.6 中修复，从该版本起不再需要今年早些时候引入的 Render Target 捕获方法。

V2.11 - 2025年4月8日

Easy Game UI v2.11¶

支持的版本：5.1 / 5.2 / 5.3 / 5.4 / 5.5

  • 将输入提示系统更新至 1.5 版，新增显示按住和连打输入的功能
  • 游戏制作人员名单的“退出”按钮现在使用输入提示来显示长按输入的进度
  • 修改了游戏启动时的设置初始化逻辑，以避免在某些情况下应用错误的分辨率
  • 补充了全局配置中“Enable Game Benchmark in Shipping Build?”（在发行版构建中启用游戏基准测试）设置缺失的逻辑
  • 修复了使用 Global Config Exporter Tool（全局配置导出工具）时可能出现的若干导入错误
V2.1 - 2025年3月13日

Easy Game UI v2.1¶

支持的版本：5.1 / 5.2 / 5.3 / 5.4 / 5.5

  • 全新的高度可自定义游戏制作人员名单系统
  • 大量更新，以及可在任意位置使用的新通用控件
  • 在多个系统中更好地处理输入
  • 全局配置与样式系统中新增了大量设置
  • 重做了选项菜单的多个设置，使其实现起来更加简单
  • 重做了加载界面，并对存档系统做了大量改进
  • 重做了拍照模式，不再覆盖关卡的后期处理体积，并大幅改善亮度处理
  • 还有许多其他改动、改进和错误修复！

更新说明 - Easy Game UI v2.1

V2.01 热修复 - 2025年2月6日

Easy Game UI v2.01 热修复¶

支持的版本：5.5

  • 使用渲染目标系统彻底重做了屏幕截图功能，以修复 Unreal Engine 5.5 引入的一个错误：该错误会导致常规高分辨率截图在发行版构建中无法正确保存。此问题仅影响拍照模式和存档系统的缩略图截取
V2.0 - 2025年1月10日

Easy Game UI v2.0¶

支持的版本：5.1 / 5.2 / 5.3 / 5.4 / 5.5*

*由于一个引擎错误导致截图在 Unreal Engine 5.5 发行版构建中无法使用，已发布热修复以提供临时解决方案，直到该错误被官方修复。

  • 实现流程更加简单直接
  • 全新的全局配置与样式系统，可对资源包中的所有系统进行集中且精细的控制
  • 为开发者和玩家打造的全新独特基准测试工具
  • 存档系统新增版本管理机制
  • 选项菜单中新增并更新了大量设置，例如新的色彩校正设置和手柄图标切换器
  • 许多设置的配置流程更加简单，例如外部超分辨率插件（DLSS、FSR、XeSS）以及音频和玩法设置
  • 重做了 UI 导航系统，使所有控件之间的切换更加流畅
  • 对相册和拍照模式的系统进行了多项重做

更新说明 - Easy Game UI v2.0

V1.56 - 2024年11月19日

Easy Game UI v1.56¶

支持的版本：5.1 / 5.2 / 5.3 / 5.4 / 5.5*

  • Added support for Unreal Engine 5.5 with various bugfixes related to this new version:
    • 修复了标题栏输入导航无法正确注册的问题
    • 修复了多项样式默认值未被遵循的问题，该问题会导致警报横幅等控件被应用错误的样式
    • 修复了编译某些蓝图时可能发生的崩溃
  • 将内置的法语本地化从 Unreal 中的“French (French)”子语言移至主“French”语言。这应能避免一些打包问题

*支持仍处于实验阶段，且由于 UE5.5 非常不稳定，可能会存在问题。

V1.55 - 2024年10月21日

Easy Game UI v1.55¶

支持的版本：5.1 / 5.2 / 5.3 / 5.4

  • 警报横幅通用控件的多项更新与改进

    • 现在支持定时操作，当设定的计时器到期时，你可以强制触发某个操作
    • 新增用于确认分辨率更改的定时警报横幅
    • 新增当用户操作退出按钮时显示的警报横幅
    • 更新了按钮的字体和间距，以便一次显示更多按钮
    • 改进了警报横幅的整体导航与过渡效果
    • 移除了关闭警报横幅时已不再需要的多项延迟

  • 更新了暂停菜单和主菜单的布局，使其更易读并可容纳更多按钮

    • 在暂停菜单中新增“退出到主菜单”按钮

  • 在选项菜单中新增一个按钮，用于重置当前标签页的所有设置

  • 修复了烘焙内容时出现的 80 多个次要警告
  • 修复了可能导致某些关卡在独立模式下无法正确加载的问题
  • 修复了可能导致无法从主菜单删除存档文件的问题
  • 图形预设设置现在可以从超高到低无限“循环”切换，而不再卡在超高
  • 修复了可能导致选项菜单中选中错误分辨率作为当前分辨率的问题
  • 修复了相册中的一个问题：如果此前的文件夹不存在，照片将无法正确加载
  • 修复了可能导致部分设置无法正确保存的问题
  • 修复了多种可能导致手柄操作出现问题的 UI 导航情况
  • 修复了编辑器中可能出现的多种错误
  • 实现了 Easy Game UI 1.5 预览视频中展示的全新样式预设
V1.5 - 2024 年 10 月 7 日

Easy Game UI v1.5¶

支持的版本：5.1 / 5.2 / 5.3 / 5.4

  • 重要新增：全新的 Easy Save Game UI 资源包已实装
  • 选项菜单新增功能：每个选项的描述、预览图片以及改进后的重置操作
  • 新增并更新了多种常用控件
  • 对拍照模式和输入提示系统进行了更新
  • 修复了输入提示系统中的一个问题，该问题可能导致在中文、日文或韩文环境下使用 Unreal 时按键无法被正确识别
  • 还有许多其他改进、错误修复和小幅改动

更新说明 - Easy Game UI v1.5
