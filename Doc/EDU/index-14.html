游戏制作人员名单¶

本节将详细介绍使用 Game Credits 系统所需的全部内容，无论是游戏过程中的制作人员名单、作为开场播放的名单，还是在菜单中显示的名单。

Game Credits 系统包含两个主要部分：定义所有制作人员名单的 Data Table（数据表），以及定义这些名单以何种方式、在何时播放的 Context（上下文）。

制作人员名单设置¶

  1. 首先需要定义用于存放所有制作人员名单的 Data Table，为此，请在任意位置新建一个 Data Table（在内容浏览器中右键单击，然后选择 Miscellaneous 下的 Data Table）

    如果想查看演示制作人员名单的设置示例，可以查看 EasyGameUI/EasySystemMenus/EasyGameCredits 文件夹中的 DT_DemoCreditsDefinition

  2. 然后在 Row Structure 中选择 F_CreditsSectionDefinition


    注意不要选择 CreditsImageSectionDefinition 或 CreditsTextSectionDefinition

  3. Data Table 创建完成后，打开它并添加第一行（行名称并不重要，保留默认名称即可）

  4. 在行编辑器中，你现在可以为一个制作人员名单分区定义所有参数，包括任何样式覆盖（Style Override）

    一个分区可以由一张图片和/或任意数量的文本块组成，下面详细拆解所有设置

    • Section Title 分区的全局标题，如果不需要标题可以留空（例如以一张图片作为该分区的开头时）
    • Override Title Style? 勾选此选项可覆盖全局样式，仅为此标题应用特定样式
      注意：所有元素的默认样式可通过 Global Styling 数据资源更改
    • Section Title Style Override 当 Override Title Style 设置为 True 时，用于覆盖文本的字体、大小、颜色和内边距

    • Section Type 该分区应使用的动画类型

      • Fade 该分区的全部内容会在单个页面中居中显示，并以淡入/淡出方式出现
      • Scroll 该分区的内容会带有滚动动画，适合较长的内容

      你可以按任意顺序组合 Fade 和 Scroll 分区；如果连续存在多个 Scroll 分区，它们会被合并并放在一起

    • Section Global Parameters 每种分区类型各项动画的参数

      • Fade In Duration 若分区类型为 Fade，则该项表示淡入的持续时间（秒）
      • Fade Out Duration 若分区类型为 Fade，则该项表示淡出的持续时间（秒）
      • Fade Credits Section Duration 若分区类型为 Fade，则该项表示分区的完整持续时间（秒，在淡入/淡出时长之外额外计算）
      • Scroll Credits Speed 类型为 Scroll 的分区的滚动速度

    • Section Content Order 如果分区同时包含图片和文本，可通过该选择器更改它们的显示顺序。你可以先显示全部文本再显示图片，也可以反过来。

    • Section Text Content 该数组可包含分区的多组文本内容，每组可包含一个角色（Role）以及一个或多个姓名，并可按需包含其样式覆盖

      • Role Name 所定义成员的角色名称，可留空
      • Role Name Position 角色文本相对于成员姓名的位置，可位于左侧、上方或右侧
      • Members Name 成员姓名，你可以按任意方式排版文本（例如每行一个姓名、所有姓名以空格分隔写在一行等）
      • Role Text Style Override & Names Text Style Override 与标题样式覆盖相同，在勾选 Override Style checkbox 后，可更改文本的字体、大小、颜色和内边距

    • Section Image Content 你要在分区中显示的任何图片的定义，图片将按照画笔设置中定义的“Image Size”显示

制作人员名单配置¶

  1. 完成 Data Table 的设置与配置后，打开你正在使用的 Global Config 数据资源，然后进入 Game Credits Section

  2. 在这里，你可以定义制作人员名单可播放的各种“Context（上下文）”。默认情况下已定义 3 个制作人员名单上下文：

    • Menus 上下文由系统用于从暂停菜单和主菜单中显示制作人员名单 （若已启用）
    • Intro Credits 上下文由系统用于显示开场制作人员名单 （若已启用）
    • Gameplay 上下文可用于任何其他场合

    你可以随意创建新的上下文，或根据具体需求修改现有上下文，下面详细列出所有可调整的设置：

    • Credits Definition Data Table 应将先前为制作人员名单创建的 Data Table 设置到此变量中

    • Credits Background Definition 用于定义使用该上下文播放制作人员名单时应采用何种背景的各项参数

      Background Type 枚举定义了要使用的背景类型，共有四种选择：

      • Transparent 不显示任何背景，其他所有背景设置都会被忽略
      • Solid Color 显示在背景类型选择器下方定义的纯色，其他所有背景设置都会被忽略
      • Static Image 将显示单张背景图片，该图片必须在 Images 数组中定义
      • Fading Images 将按顺序显示 Images 数组中定义的所有图片，每张图片持续指定的 Fading Images Duration，并以指定时长进行交叉淡化

    • Music Reference 如果希望在播放制作人员名单期间播放音乐，可在此变量中添加，音乐将无限循环直到名单结束

    • Music Fade Out Duration 制作人员名单完成或被玩家关闭后，音乐淡出的持续时间（秒）

    • Credits Input and Game Parameters 与输入处理、游戏状态和完成处理相关的各项设置

      • Allow Skip? 若为 True，玩家将拥有用于跳过制作人员名单的输入
      • Skip Hold Duration 玩家在跳过制作人员名单之前必须按住跳过按钮的最短时长
      • Allow Credits Pause? 若为 True，玩家将拥有用于暂停制作人员名单的输入

      • Allow Speed Up? 若为 True，玩家将拥有用于加快制作人员名单播放的输入

      • Action On Credits Completion 制作人员名单完成或被跳过时应执行的操作

        • Go Back To Main Menu 自动加载全局配置中指定的主菜单关卡
        • Load Specified Level 加载变量 Level to Load On Credits Completion 中指定的关卡
        • Go Back To Gameplay 移除制作人员名单并恢复到之前的“游戏进行中”状态
        • Wait For Manual Exit 制作人员名单完成时不做任何操作，玩家必须按住跳过/退出按钮，随后执行 Go Back To Gameplay 操作

      • Pause Game During Credits 播放制作人员名单时是否暂停游戏

      • Pause State To Apply On Credits Completion 制作人员名单完成后应应用的暂停状态：强制暂停游戏、强制取消暂停，或恢复到此前的状态（即制作人员名单开始前的状态）

      注意

      对于 Menus 和 Intro Credits 上下文，建议不要更改 Credits Input and Game Parameters 部分中的任何设置，因为这些设置已针对暂停菜单和主菜单调整至最佳。你可以自由更改该上下文中的其他任何设置

  3. 定义好上下文之后，如果你在全局配置（Global Config）中启用了 Display Game Credits Button in Menus? 设置，就可以直接从暂停菜单或主菜单中测试制作人员名单了

  2. 接着，通过该 HUD 引用调用 Play Credits 函数

  3. 在该函数中，你只需填写要使用的上下文名称，例如 Gameplay
