JSON 编译错误修复¶

在极少数情况下（如果受到影响，通常很容易察觉），你在重启项目时可能会遇到 JSON 插件节点丢失的问题，即使该插件已经启用。（如果你只是忘记启用插件，重启项目应该就能修复节点；最坏的情况下，你可能需要重新就地下载该资源来修复它）
这可能由插件或 C++ 模块的加载冲突导致，你可以简单地进入 BP_EasyMainGameHUD，检查重启项目后是否出现编译错误或 JSON 节点丢失来进行确认。

如果遇到此问题，你可以通过修改 Json 插件的加载顺序（Load Order）来修复。

  1. 前往你的 Unreal Engine 安装目录，然后进入文件夹 [Engine version]\Engine\Plugins\JsonBlueprintUtilities
  2. 进入该文件夹后，用文本编辑器打开 JsonBlueprintUtilities.uplugin 文件

  3. 你应该会看到类似以下的内容：

  4. 将所有 "LoadingPhase" 的值从 "Default" 修改为 "PreDefault"

  5. 重启项目并再次测试，你可能需要重新下载该资源才能获得干净且无错误的版本，但完成此修复后该问题应该不会再出现。

注意

Blueprint File Utilities 插件也可能出现类似问题，此时只需在 [Engine version]\Engine\Plugins\BlueprintFileUtils 文件夹中的 BlueprintFileUtils.uplugin 里重复上述步骤即可

系统测试¶

完成前面的所有步骤后，你可以测试该资源，看看它是否已正确集成并完全正常工作。
为此，请前往 EasyGameUI/Maps 并打开 L_EGUI_MainMenuDemoLevel。然后开始运行，看看主菜单是否正确显示。同时请确认在你按下运行或加载到任意新关卡时，左上角会出现以下日志 Easy Game Hud Initialized。

如果主菜单正常显示，并且你获得了全部正确的日志、没有出现下面列出的任何错误，我建议你稍微试用一下该系统（选项菜单、新游戏、拍照模式等），看看是否有什么地方出现异常。
在资源的演示关卡中导航时，几乎所有系统都应该是正常的。

反之，你可能会遇到各种问题或错误，以下是你最可能遇到的一些常见问题：

“缺失插件（Missing Plugins）”通知

如果你忘记启用必需的插件，可能会看到此弹窗，请按下“Enable Missing”按钮并重启项目。

然后回头查看项目设置步骤，确认你没有遗漏任何必需的插件或设置。
如果完成此步骤后资源仍无法正常工作，你很可能需要就地重新下载它。

“严重错误：项目设置“Enable User Settings”不为 True。”

你可能忘记启用项目设置“Enable User Settings”，请回头查看项目设置步骤，确认你已应用所有必需的设置。

“严重错误：Game Instance 类未正确设置。”

你的 Game Instance 可能未正确设置，或未在项目设置中选中，请回头查看Game Instance 设置

“Easy Game HUD Initialized”完全没有显示（在你自己的关卡中游玩时）

你的 Game HUD 可能未正确设置，或未在你的 GameMode 中选中，请回头查看Game HUD 设置
