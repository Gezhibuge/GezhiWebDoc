光照与曝光

UDS 自带日月平行光与天光组件，并接管了云影、天光模式与自动曝光。这一页说明各组件的可控范围，以及用静态光照时需要注意什么。

组件而非 Actor曝光由 UDS 接管

灯光组件

UDS 内部自带三个灯光组件：代表太阳的平行光、代表月亮的平行光，以及一盏天光（Sky Light）。 具体用哪个组件、以何种方式工作，由 Sun、Moon、Sky Light 三个分类里的设置决定； 天光还额外受 Sky Light Mode 影响。

也可以让 UDS 去引用关卡里现成的灯光 Actor，而不是用内置组件，但除了第三方资产或插件明确要求引用灯光 Actor 的情况，都不建议这么做。 如果确实要用，有两步必须手动补上：

  • 平行光：组件上有一个 Cloud Scattered Luminance Scale，控制灯光对云的影响。 这个值无法通过蓝图设置到你的灯光 Actor 上，需要从 UDS 的 Sun 或 Moon 组件里抄到你的平行光 Actor。
  • 天光：天光组件上的 Source Type 也无法被 UDS 控制，必须与 UDS 的 Sky Light Mode 对应： 使用 Cubemap with Dynamic Color Tinting 或 Custom Cubemap 时，Source Type 要设为 Specified Cubemap；使用 Capture Based 时设为 Captured Scene。

日月平行光

太阳与月亮这两个平行光组件，有一部分属性由蓝图每帧驱动：颜色、强度、是否投射阴影、光源角度。 其余属性保持开放，你可以直接在组件上改——选中 UDS 后，在细节面板顶部的组件列表里选 Sun 或 Moon， 看到的就是一个标准平行光组件的属性面板。

影响两者的公共参数在 Directional Light 分类里；只影响单个的分别在 Sun、Moon 分类里。 日月的位置、运动与外观见 时间、日月与模拟。

云影

云影默认开启，并且与所有 Sky Mode 兼容，包括没有云的 No Clouds。 不需要的话可以在 Cloud Shadows 分类里关闭。

同一个分类里还能调：

  • 云量高/低时阴影的强度与柔和度。默认云量高时完全遮挡平行光，云量低时只部分遮挡。
  • Fog 或 Dust Amount 较高时，对平行光的遮挡比例。

Sky Mode 为体积云时，云影是按 3D 云层真实计算的，每一朵云都会在场景里投下对应的影子。 其他模式没有三维云层可投射，云影来自一张阴影纹理，其移动速度与尺度由 2D Cloud Shadows Speed 与 2D Cloud Shadows Scale 控制。

天光（Sky Light）

Sky Light Mode 决定天光立方体贴图从哪来，以及 UDS 如何控制它的强度与颜色。

模式做法适用
Capture Based 通过捕获天空生成立方体贴图。默认使用实时捕获，Sky Light 分类里可以开关。 画质优先，接受捕获开销
Custom Cubemap 使用一张静态立方体贴图，在下方 Sky Light Cubemap 指定。 天空固定、或想要特定环境光
Cubemap with Dynamic Color Tinting 用一张中性灰立方体贴图，按雾色动态染色，使环境光随昼夜变化。 动态昼夜项目，性能友好且全平台可用

Sky Light Color Multiplier 可以按时段分别给天光染色。这些倍率允许大于 1， 超过 1 时该时段的光照强度会按比例放大。

曝光

UDS 默认会应用自动曝光（Auto Exposure，引擎里也叫 Eye Adaptation）。相关设置都在 Exposure 分类里， 可以调整或关闭。

勾选 Apply Exposure Settings 后，UDS 会接管以下几项：

引擎参数UDS 中的对应设置作用
Exposure Compensation Curve — 根据画面整体亮度把曝光往上或往下推。
Exposure Compensation Exposure Bias（分时段、分天气） 针对性地让夜晚更亮、阴天更暗。
Metering Mode Exposure Metering Mode 是否启用自动曝光以及用哪种测光方式。改成 Manual 会关闭自动曝光，但仍可使用下面的曝光偏移。
MinEV100 / MaxEV100 Exposure Brightness Range 自动曝光试图适应的亮度区间。

如果调不准，可以在视口里打开 Show → Visualize → HDR (Eye Adaptation)， 直接看到自动曝光内部在做什么，再对照后处理体积或相机里的曝光设置一起调。

使用静态 / 固定光照

UDS 默认全部使用可移动（Movable）光源，但也支持静态光照。要改成静态或固定（Stationary）， 请在 UDS 细节面板里对应分类（Sun、Moon、Sky Light）中找到 Mobility 设置， 从暴露出来的这一项改，不要直接改灯光组件上的 Mobility。

构建光照之后，仍可以调整部分天空设置，但任何改变光源本身或位置的设置都会让光照构建失效，需要重新构建。 另外，太阳如果是静态或固定光照，运行时 Time of Day 就无法变化了。
