Unreal Engine · 动态天空与天气

Ultra Dynamic Sky
中文文档

Ultra Dynamic Sky（下称 UDS）是一套用蓝图实现的天空系统：昼夜循环、体积云、日月、星空、雾与光照都在同一个 Actor 里完成，并配套 Ultra Dynamic Weather（UDW）扩展出完整的天气系统。这份文档翻译自官方 9.7 版说明， 按功能模块重新分页，参数名与引擎内保持一致。

官方文档是一份很长的单页说明，共 180 多个小节。这里把它按「天空 → 天气 → 常见问题 → 技术说明」拆成了十几个页面， 并补上了各小节对应的视频（B 站，UP 主 Gezhibuge 翻译）。所有参数名保留英文原文，因为你在细节面板里看到的就是英文。

开始之前

UDS 是一个 Actor，拖进关卡即可工作。但有一件事必须先做对：清掉关卡里原有的天空与光照 Actor， 否则你会得到两套天空叠加、或整体过曝的结果。具体清单见 安装与基础设置。

另一个常见的误解是把它当成“只负责好看”的美术资源。实际上 UDS 会接管关卡里的主光源、天光、雾和曝光， 这些都会影响场景里其他 Actor 的观感，所以调整顺序建议是：先定天空与时间，再调场景光照，最后做后处理。
