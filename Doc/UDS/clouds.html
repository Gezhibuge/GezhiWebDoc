云

四种云的渲染方式与各自的参数：体积云的分层与采样、2D 动态云的分布、静态云纹理与体素云的复用关系，以及云的移动与高空云丝。

四种 Sky Mode体积云为主

UDS 里“云”不是一个整体，而是由 Sky Mode 决定用哪套渲染方式，再各自有独立的参数分类。 这一页按四种模式分别说明，最后是它们共用的云移动与高空云丝。

体积云（Volumetric Clouds）

Volumetric Clouds 分类下的主要设置：

设置说明
Volumetric Cloud Rendering Mode 决定引擎如何把体积云画到屏幕上，本质是渲染器 cvar r.volumetricrendertarget.mode 的封装。各模式按它们优先保障的渲染环节命名，性能与画质取舍不同，具体差别见每个模式的悬停提示。
Bottom Altitude 云层底部的高度。要改云的高度请用这一项，不要移动 UDS Actor——它只影响云层，不会连带改变大气与雾。
Volumetric Clouds Scale 整体缩放云场。想让云“更大片”时调它，而不是逐个改噪声。
View Sample Scale 决定云的采样次数。云看起来噪点重、有颗粒感时提高它可以让云更平滑，代价是性能。

如果需要在关卡的特定区域直接控制云量——例如让某座山周围始终没有云——用 Volumetric Cloud Painter（体积云绘制器），详见 其他功能 · 云绘制。

云的具体形状来自一张 Cloud Profile LUT 纹理。想自己雕刻云型，可以用 Cloud Profile Authoring Tool：在关卡编辑器工具栏的 Ultra Dynamic Sky 下拉菜单里启动， 或直接运行 Blueprints/Tools 下的编辑器工具。

附加云层（Additional Cloud Layers）

同一个分类里还有一个 Additional Cloud Layers 数组，可以在主云层之上或之下增加额外云层。 每加一层都会增加 GPU 开销。每一层的外观参数都是相对主云层来设置的。

注意

附加云层只是视觉层：云影只由主云层投射；需要在云层高度发生的事情（例如 UDW 的闪电闪光）也都发生在主云层的高度。

每条附加层默认 Inherited Cloud Coverage = 1、Independent Cloud Coverage = 0， 也就是完全跟随主云层的云量变化。如果改用 Independent Cloud Coverage 让该层使用自己的云量， 可以在运行时调用 UDS 上的 Set Additional Cloud Layer Coverage 来改。

2D 动态云

这个分类里是从柔化、明暗到噪声纹理的全部 2D 云参数。需要先理解一点： 2D 云是画在天空球上的材质效果，并不存在于关卡的三维空间里。 因此 Cloud Height 之类的参数只是在控制天空材质里的透视畸变，不会真的把云“抬高”。

分类的 Advanced 折叠区里还有分布控制，例如加大地平线附近的云量、或减少月亮周围的云量。

静态云（Static Clouds）

静态云是一种省性能的云：把云画成一张静态纹理，纹理里预先烘焙了不同光照角度， 从而在日月改变方向时仍能近似出简单的受光变化。这个分类里可以更换纹理、控制旋转。

资源里自带三张静态云纹理。也可以自己做：Static Clouds Authoring Tool 能把 UDS 当前的体积云渲染成一张新的静态云纹理， 入口同样在工具栏的 Ultra Dynamic Sky 下拉菜单，或 Blueprints/Tools 下。

体素云（Voxel Clouds）

体素云是把云渲染成硬边立方体的另一种表现方式，适合体素风格的项目。它并不是独立的云系统—— 本质上只是体积云的一种渲染样式，因此沿用体积云分类里的大部分设置（云纹理、高度、颜色等）， Voxel Clouds 分类里只放它独有的参数。

也因为它建立在体积云之上，体积云绘制器和径向风暴的局部云量同样会作用于体素云。

云的移动（Cloud Movement）

设置说明
Cloud Speed、Cloud Direction 云的速度与方向。若关卡里存在 UDW，方向会完全由 UDW 的风向接管。
Cloud Phase 云的“相位”。当 Cloud Speed 为 0 时特别有用：云静止，你可以用相位一点点试出想要的云形。
Randomize Cloud Formation On Run 每次运行时随机生成初始云形，与其他移动设置相互独立。
Clouds Move With Time of Day 让云的移动与时间流逝绑定。适合时间倍率会变化的场景，例如做一段延时摄影时保持云与时间同步。

高空云丝（Cloud Wisps）

云丝是天空最上层那圈轻薄的高空云，除了 Space 模式之外，所有 Sky Mode 下都会渲染。 它的做法是采样一张灰度纹理，用采样到的值给天空叠一层随昼夜变化的云丝颜色。

不透明度由两个值控制：云量低时用一个，云量高时用另一个，中间自动过渡。 纹理可以在 Cloud Wisps Texture 里换成自己的图——注意必须是灰度图，因为只采样 R 通道。

云丝默认带一点流动效果：随时间与动态云一起对纹理做偏移扭曲，并用渐隐加偏移映射的方式做成无缝循环。 效果强度可以在分类里调整或直接关闭。
