输入提示系统¶

内置的输入提示（Input Prompts）系统可让你轻松显示按键图标，引导玩家了解可用的按键绑定。这些输入提示已用于本资源包中的大多数 UI，在以下指南中，你可以了解如何在自己的系统中使用它们：

  • 单个输入提示控件
  • 多个输入提示控件
  • 富文本输入提示
  • 世界输入提示

单个输入提示控件¶

基础输入提示控件允许你在任意控件中显示单个自定义输入提示，既可以使用硬编码按键，也可以通过输入操作（Input Action）动态获取

  1. 在你的项目中，打开想要显示简单输入提示的控件

  2. 在「调色板（Palette）」标签页中搜索 Easy Input Prompts 分类，然后将 WBP Easy Input Prompt Displayer 控件拖放到任意容器中（画布面板、水平框、按钮等）

  3. 添加后，你会在细节（Details）面板的 Easy Config 分类下看到许多可用变量

    Keys Definition 用于控制控件需要显示哪些按键

    • Use Input Action? 如果想使用输入操作来显示输入，请勾选此复选框。若想硬编码按键，则不要勾选

    • Input Action Definition 如果勾选了上一个复选框，此时需要填写你想显示的输入操作的相关信息

      在下拉列表中选择输入操作（Input Action），并选择要从中获取按键绑定的输入映射上下文（Input Mapping Context）

      如果所选输入操作在映射上下文中每个设备对应多个按键，则需要指定要显示的按键索引。

      在下面的示例中，键盘按键有 4 个索引，手柄按键有 2 个索引。如果想显示“D”和“Thumbstick X-Axis”，需要在对应字段中分别输入索引 3 和 1。

    • Hardcoded MNK Key 与 Hardcoded Gamepad Key

      如果未勾选上一个复选框，此时可以通过两个下拉列表并输入按键名称，来指定想要显示的硬编码按键

      无需同时填写两个按键。如果只想为单个设备显示按键，只填其中一个即可

    • Device Display Conditions 此变量有三个选项，用于控制按键的显示：

      • Dynamic Based on Device 会根据当前使用的设备，显示手柄按键或键鼠按键
      • Only Mouse & Keyboard Keys 无论使用何种设备，都只显示键鼠按键
      • Only Gamepad Keys 无论使用何种设备，都只显示手柄按键

    • Invalid Key Hide Conditions 此变量控制当按键无效时（例如设备不匹配、找不到按键等）输入提示应如何反应

      • Keep Input Prompt and Text Visible 当使用其他设备或按键无效时，输入提示和文本仍然可见
      • Hide Input Prompt Only 当使用其他设备或按键无效时，输入提示会被隐藏，但文本仍可显示
      • Hide Input Prompt and Text 当使用其他设备或按键无效时，输入提示和文本都会被隐藏

      例如：如果将输入提示设置为仅显示手柄按键，并把此变量设为 “Hide Input Prompt Only”，那么当玩家使用键盘而不是手柄时，就可以隐藏该输入提示

    • Input Type 此变量用于在三种选项中选择按键应显示的输入类型：

      • Single Tap 适用于大多数场景的基础单击按键
      • Hold 需要按住指定时长的按键
      • Button Mash 需要在指定时长内反复按下的按键

    Styling Definition 可用于控制按键大小、在按键旁添加可选文本，以及更改输入提示的整体样式

    • Icon Size 此设置以像素为单位定义所显示输入提示图标的大小
    • Additional Text 在按键旁显示的可选文本。如果无需显示文本，可以留空
    • Text Styling 一组用于控制文本字体、变换策略和对齐方式的选项
    • Text Position 用于控制文本相对于按键图标位置的选项。只能选择右对齐和左对齐
    • Text Padding 为文本添加的可选内边距

多个输入提示控件¶

多输入提示控件允许同时显示多个自定义输入，但与简单输入提示控件相比，它对上述图标的样式和显示的控制要略少一些

  1. 在你的项目中，打开想要显示多输入提示的控件

  2. 在「调色板（Palette）」标签页中搜索 Easy Input Prompts 分类，然后将 WBP Easy Multi Input Prompt Displayer 控件拖放到任意容器中（画布面板、水平框、按钮等）

  3. 添加后，你会在细节（Details）面板的 Easy Config 分类下看到许多可用变量

    • Keys Definition 是一个数组，你可以在其中列出所有想显示的按键；每个按键的配置与简单输入提示的按键定义完全相同
    • Styling Definition 可用于控制所有所显示图标的样式（它们将共用同一样式），其配置与简单输入提示的样式定义完全相同
    • Spacing 定义每个所显示输入图标之间的间距

世界输入提示¶

世界输入提示（World Input Prompt）可以轻松地直接在 3D 世界中显示输入提示。系统随后会使用多输入提示控件（Multi Input Prompts widget）来显示所需的输入

  1. 要在关卡中使用它，请前往 EasyGameUI/EasyInputPrompts/Core 文件夹，找到 BP_EasyWorldInputPrompt

  2. 将其拖放到关卡中 3D 输入提示应出现的位置。红色箭头指示该控件将从哪个方向可见

  3. 随后你可以在 Details 面板中、Easy Config 分类下访问所有设置

    • Keys Definition 是一个数组，你可以在其中列出想显示的所有按键，每个按键的配置与简单输入提示的按键定义完全相同

    • Display Type 定义控件在 World 与 Screen 之间以何种方式渲染

      • World 控件完全作为 3D 世界对象运行（在世界中具有固定位置与旋转，并且当玩家绕文本移动时具有正确的视差效果）

      • Screen 控件会尝试相对于其位置在屏幕上保持固定大小。它还会自行旋转，以便无论摄像机角度如何都保持在屏幕上

    • Resolution Multiplier 定义控件应放大多少倍。数值越高画质越好，但性能开销也越大，此设置在很大程度上取决于玩家能靠多近以及控件有多大

    • Styling Definition 允许你控制所有已显示图标的样式（它们将共用同一套样式），其配置与简单输入提示的样式定义完全相同
    • Spacing 定义每个已显示输入图标之间的间距
