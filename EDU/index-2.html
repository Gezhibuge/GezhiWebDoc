项目设置¶

  1. 打开你的虚幻引擎项目，进入 “Edit”（编辑）菜单，打开 Plugins（插件）标签页

  2. 然后输入 “JSON”，启用 JSON Blueprint Utilities 插件（现在先不要重启）

  3. 接着输入 “File Utilities”，启用 Blueprint File Utilities 插件（也不用重启）

  4. 完成后，再次进入 “Edit”，打开 Project Settings（项目设置）

  5. 输入 “enable user”，确认 Enable User Settings 选项旁边的复选框已勾选（true）

  6. 然后输入 “render focus”，在 Render Focus Rule 的下拉框里选择 Never

  7. 接着在 Engine 下的 Rendering 分类中，确认已启用 Lumen，并勾选 Support Hardware Ray Tracing
    这一项不是必须的；但不开启的话，选项菜单里的 “Hardware Ray-Tracing Lumen” 开关将不起作用

  8. （可选）搜索 “flush keys”，确认 Should Flush Pressed Keys on Viewport Focus Lost 未勾选（false）
    关闭它可以让 UI 对键盘输入的响应更好

  9. 现在可以关闭虚幻引擎，进入下一节了
