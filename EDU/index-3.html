资源安装¶

项目设置提醒

如果你在完成 项目设置 一节之前就做了下面的步骤，请删除资源包文件夹并重新下载，以免出现问题

从 FAB 安装¶

  1. 要从 FAB 安装该资源，请打开 Epic Games 启动器并进入 FAB 标签页

  2. 点击 My Library（我的库）标签，在搜索框里输入 Easy Game UI

  3. 然后点击 + 按钮把它添加到你的项目

  4. 在弹出的窗口中选择要使用该资源包的项目，然后等待导入完成。完成后即可进入下一节

    FAB 安装后蓝图报错

    如果从 FAB 安装后出现大量类似下图的蓝图编译错误，请尝试移除所有已安装版本，然后重新下载资源

    要清除本地已安装的所有版本并重新下载：点击该产品，在弹出的窗口中点 Add to Project 按钮旁边的三个点，选择 Remove Local Content（如果有这一项），然后重新添加到项目

    如果问题依旧，请通过 Discord 或邮件（nerwy.ytb@gmail.com）联系我，我会帮你解决

从源码构建安装（Discord）¶

源码构建版本发布在 Discord 上，面向已验证购买的用户

  1. 要从 Discord 提供的源码构建安装，请先根据你的引擎版本确认需要的版本，并下载对应文件

  2. 然后解压下载的压缩包，你会得到一个包含资源文件的虚幻项目文件夹

  3. 在这个项目文件夹中进入 Content，复制其中的 EasyGameUI 文件夹

  4. 最后打开你自己的虚幻项目文件夹，把这个 EasyGameUI 文件夹粘贴进去（放在项目的 Content 文件夹里）
