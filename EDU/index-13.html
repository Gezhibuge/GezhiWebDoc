拍照模式¶

警告

在 Unreal Engine 5.5 Shipping 构建 中，由于引擎的一个 bug，截图将无法正确捕获。这不会影响其他任何 UE 版本；但如果你使用的是 UE5.5，需要将全局配置中的截图捕获方式（Screenshot Capture Method）改为 Render Target。如果你不打算在 Shipping 构建中启用拍照模式，可以使用 High Resolution Capture Method 以获得更高画质。

使用 Demo 玩家控制器设置拍照模式¶

如果你使用的是提供的 BP_EGUI_DemoPlayerController，那么拍照模式所需的一切都已配置好。默认情况下，你可以通过暂停菜单或游戏中的以下按键打开拍照模式

为自定义玩家控制器设置拍照模式¶

  1. 在你包含角色所有主要输入的 Input Mapping Context 中，使用 IA_TogglePhotoMode 设置一个用于打开拍照模式的输入

    你可以随意使用任何按键，此设置示例可在 EasyGameUI/DemoContent/Inputs/IMC_MainGameInputs 中找到

  2. 完成后，在你的玩家控制器中添加 IA_TogglePhotoMode 输入操作事件

  3. 然后，使用 Get HUD 函数获取 HUD Class 引用

    注意

    如果你是在玩家控制器之外执行此操作，则必须为 Target 引脚添加连接，例如使用 Get Player Controller 函数。你也可以使用系统函数 GetEasyGameHUD

  4. 然后，从 HUD 引用调用 Open Photo Mode 函数

  5. 最后，将其连接到输入操作事件的 Started 引脚
    请注意，默认情况下某些版本中只显示 Triggered 引脚，你需要点击输入事件节点底部的箭头才能显示 Started 引脚

  6. 如果你希望在拍照模式打开/关闭时添加任何逻辑，可以使用提供的事件 Photo Mode Closed，用法如下：

信息

附加工具¶

在 EasyGameUI/EasyPhotoMode/Core/VolumeBlueprints 文件夹中，你会找到几个在设置拍照模式时可能有用的蓝图

  • BP_EPM_CameraBlockingVolume

    放置在世界中后，此阻挡体积会阻止拍照模式的摄像机越过边界，充当一堵隐形墙，可用于封锁一些禁止进入的区域。

    你只需将其放置在你的世界中，并在所需位置缩放即可。

    该阻挡体积仅在玩家打开拍照模式时启用，因此无需担心它会影响正常游戏玩法

  • BP_EPM_PhotoModeDisablerVolume

    此体积可用于在特定区域阻止拍照模式的激活。比如你不想让玩家在房屋内或首领战场中打开拍照模式，只需放置此体积覆盖被封锁的区域即可！
