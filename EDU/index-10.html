暂停菜单¶

使用演示玩家控制器的暂停菜单设置¶

如果你使用的是提供的 BP_EGUI_DemoPlayerController，那么暂停菜单的一切都已设置好，默认情况下你可以在游戏中使用以下输入打开暂停菜单

如果你想编辑 Easy Pause Menu 控件，可以在 EasyGameUI/EasySystemMenus 文件夹中找到它。你也可以通过全局样式系统更改显示的 Logo

自定义玩家控制器的暂停菜单设置¶

如果你没有使用提供的玩家控制器，可以按照以下逻辑设置暂停菜单

  1. 在包含角色所有主要输入的 Input Mapping Context 中，使用 IA_OpenPauseMenu 设置一个用于打开暂停菜单的输入

    可以随意使用任何按键，你可以在 EasyGameUI/DemoContent/Inputs/IMC_EGUI_DemoInputs 中找到此设置示例

  2. 完成后，在玩家控制器中添加 IA_OpenPauseMenu 输入操作事件

  3. 然后，使用 Get HUD 函数获取 HUD Class 引用

    注意

    如果你在玩家控制器之外执行此操作，必须为 Target 引脚添加连接，例如使用 Get Player Controller 函数。你也可以使用系统函数 GetEasyGameHUD

  4. 然后从 HUD 引用调用 Open Pause Menu 函数

  5. 最后，将它连接到输入操作事件的 Started 引脚
    请注意，默认情况下某些版本中只显示 Triggered 引脚，你需要点击输入事件节点底部的箭头才能显示 Started 引脚

  6. 如果你想在暂停菜单打开或关闭时添加任何逻辑，可以使用提供的 Widget Closed 事件，具体用法如下：

其他指南¶

关于 Escape 键的提示

默认情况下，Escape 键会关闭游戏，不过你可以在 Editor Preferences（Edit > Editor Preferences）中更改它。
只需搜索 Stop，并将与 Stop - Stop simulation 关联的输入重新绑定为比如 Shift+Escape。这样就能在编辑器中使用 Escape 键，而不会停止游戏

禁用暂停菜单按钮
  1. 如果你想禁用暂停菜单中的按钮，请打开 Easy Pause Menu 控件

  2. 然后在 Hierarchy 面板或选项卡中，在 ButtonsContainer 面板下选择你想要禁用的按钮

  3. 然后，在 Details 面板中，将 Fully Disable Button? 变量设置为 True

  4. 如果你还想禁用该资源的整套功能，可以查看全局配置变量，大多数系统都可以在那里禁用。

更新暂停菜单背景图片
  1. 如果你想更新暂停菜单的背景，请打开 Easy Pause Menu 控件

  2. 然后在 Hierarchy 面板或选项卡中找到 BackgroundImage 控件并点击它

  3. 然后，在 Details 面板中找到 Easy Config 部分，在这里你可以修改背景的任何设置，包括图像纹理
