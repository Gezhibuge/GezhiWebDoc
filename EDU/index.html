欢迎！¶

本文档会讲清开始使用 Easy Game UI 3.0、并在自己的项目里用起来所需的全部内容。

请注意，本文档仅适用于 Easy Game UI 3.0 或更新版本（2026 年 5 月 28 日之后下载）。
如果你已经下载了资源包、但不确定版本，请打开根目录 “EasyGameUI” 文件夹中的 “README” 文件查看。

如果你使用的是旧版本资源包，请查阅旧版文档。
