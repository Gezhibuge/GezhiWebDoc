游戏 HUD 设置¶

和 Game Instance 一样，先确认你的项目是否已经使用了自定义 Game HUD 类。
可以在 Project Settings > Map and Modes 里查看，也可以打开你自己创建的游戏模式查看 HUD Class 设置。

然后根据你看到的情况，判断下面三种情形中哪一种适用于你的项目：

情形 A：使用引擎默认的 Game HUD

你看到的：HUD Class 下拉框里显示的是默认的 HUD 类

这说明你还没有自定义 Game HUD，请直接按下面的情形 A 步骤操作。

情形 A 步骤

情形 A
你还没有自定义 Game HUD 类¶

要使用资源包提供的 HUD Class，只需把 BP_EasyMainGameHUD 类加到你的游戏模式里。

  1. 如果你已经有游戏模式，打开它；或者进入 Projects Settings > Map and Modes，在 Selected GameMode 下找到 HUD Class，把值改成 BP_EasyMainGameHUD

  2. 如果还没有游戏模式，建议先看 虚幻引擎官方文档，了解并创建自己的 GameMode 类，然后再回到第 1 步。

    也可以直接使用自带的演示游戏模式（GM_EGUI_DemoGameMode）：在项目设置或 GameMode 下拉框里选中它，就会同时使用演示用的玩家控制器、角色与正确的 HUD Class。

    自带的游戏模式、玩家控制器与角色都可以在 EasyGameUI/DemoContent/ 下找到

注意

如果你有多个游戏模式或关卡覆盖了默认 GameMode 类，记得在这些覆盖里也设置 HUD Class！

情形 B：已有自定义蓝图 Game HUD

你看到的：HUD Class 显示的是自定义名称（例如 BP_MyGameHUD）

这说明你已经有自定义 Game HUD。打开它，看右上角的 Parent Class（父类）。

如果父类是引擎通用的 HUD，请按下面的情形 B 步骤操作。

情形 B 步骤

情形 B
你有自定义的纯蓝图 Game HUD 类¶

  1. 在你自己的 Game HUD 里点击 Class Settings，打开细节面板

  2. 在 Class Options 分类下找到 Parent Class “HUD” 设置

  3. 点开下拉框，搜索 BP_EasyMainGameHUD 并选中

  4. 虚幻可能会弹出警告窗口，点击 Reparent 忽略即可

  5. 接着，如果你的 HUD 里有 Event Begin Play，先找到它（在蓝图中按 Ctrl + F 搜索）

  6. 右键它，选择 Add Call to Parent Function

情形 C：继承自自定义类或 C++ 的 Game HUD

你看到的：有自定义 Game HUD，但右上角的 Parent Class 不是默认的 HUD（例如派生自插件、C++ 类，或本身就是 C++ 类）

这说明你的 Game HUD 派生自其它类或本身是 C++ 类，请按下面的情形 C 步骤操作。

情形 C 步骤

情形 C
你有自定义的 C++ Game HUD 类（或派生自自定义 C++ 的蓝图）¶

  1. 进入 EasyGameUI/Core 文件夹，打开 BP_EasyMainGameHUD 类

  2. 在这个 HUD 类里点击 Class Settings，打开细节面板

  3. 在 Class Options 分类下找到 Parent Class “HUD” 设置

  4. 点开下拉框，搜索你自己的 HUD 类名并选中

  5. 虚幻可能会弹出警告窗口，点击 Reparent 即可

  6. 然后，如果你自己的 HUD 类（不是 Easy Main Game HUD 类）里有 Any Key 节点，找到它，并复制它后面接的逻辑

  7. 回到 Easy Main Game HUD 类，找到 Any Key 节点，按你的需要把你复制的逻辑接在它后面


    如果复制的逻辑里包含宏节点，它们不会被正确复制，需要在 Easy Main Game HUD 类里重新实现

  8. 最后，记得在你的游戏模式里选中 BP_EasyMainGameHUD：可以在 Project Settings > Map & Modes 里改，也可以直接在 GameMode 类里改

注意

如果你有多个游戏模式或关卡覆盖了默认 GameMode 类，记得在这些覆盖里也设置 HUD Class！

采用这种重设父类的方式后，你仍然可以在自己的 HUD 类里继续写游戏逻辑，不需要转移或修改资源包 HUD 类里的任何内容。
