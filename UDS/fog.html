雾与天空颜色

雾的密度、高度衰减与起始距离如何由云量和尘埃推导；体积雾的开启与全局体积材质；以及 Sky Atmosphere 与 Simplified Color 两种配色方式。

雾与能见度两种配色方案

雾密度（Fog Density）

Fog Density 分类决定高度雾的密度、高度衰减和起始距离。其中密度部分不是单一数值，而是 “基础值 + 由云量、雾、尘埃各自追加的量”：

  • Density：雾随距离变浓的程度，也就是浓淡。
  • Height Falloff：雾在雾组件高度之上消散得多快。

密度有基础值，另有 Cloud Coverage、Fog、Dust Amount 三项的追加值； 高度衰减则是基础值加上“多云 / 有雾 / 有尘”三种状态的取值——这三种是直接取用，不是相加。

雾的起始距离由密度推导：一个“低密度时的起始距离”加上一个“密度达到多少时起始距离归零”， 后者用于让雾能紧贴镜头。

雾颜色（Fog Color）

这个分类里是高度雾的颜色设置，但它们实际怎么被使用，取决于项目设置 Support Sky Atmosphere Affecting Height Fog：

项目设置雾颜色的来源建议
开启（新项目默认） 雾色直接由天空大气推导。多数情况下 UDS 上的 Fog Color 设置只有一部分会生效。 保持开启，通常能得到正确的结果
关闭 雾完全使用 Fog Color 分类里的设置。 需要单独、精确控制雾色时使用

如果 Color Mode 用的是 Simplified Color，上面这段可以忽略——该模式下根本没有启用天空大气， Fog Color 里的设置会全部生效。

体积雾（Volumetric Fog）

体积雾是引擎的渲染特性：在镜头附近渲染更精细的雾，能接收并散射本地光源的光，还能被体积材质或粒子改变颜色与消光。 UDS 在 Volumetric Fog 分类里提供了开关与参数。

分类顶部是开关、整体消光（extinction）和渲染距离。下面还有太阳与月亮的 Volumetric Scattering Intensity，分别控制这两个光源把体积雾照亮的程度。

全局体积材质（Global Volumetric Material）

同一分类里可以开启全局体积材质，从而对消光与颜色做统一的控制。它包含四项，均可在此开关：

功能作用前置条件
基于纹理的 3D 噪声给消光叠加噪声，让雾有层次和变化。—
用天气遮罩笔刷遮住体积雾指定哪些区域不生成体积雾。使用 UDW 的天气遮罩工具
地面雾（Ground Fog）在距离场正上方增加额外的雾消光。项目需开启生成 Mesh Distance Fields
水下雾在水位以下使用单独的消光与反照率。使用 UDS 的 Water Level 分类

尘埃（Dust）

Dust 分类用来模拟空气里充满灰尘、烟尘或其它悬浮颗粒的状态。 Dust Amount 会同时影响雾的密度、高度衰减和雾色；当它为 1 时，雾色取 Dust Color。 尘埃对密度的具体影响方式在 Fog Density 分类里设置。

注意

关卡里存在 UDW 时，Dust Amount 会由天气状态接管。

天空颜色：Sky Atmosphere

Color Mode 为 Sky Atmosphere 时，配色的主要控制在 Sky Atmosphere 分类里：

设置作用
Rayleigh Scattering决定天空的主色调，可以按白天、夜晚、晨昏分别调。
Sunset / Sunrise / Twilight对应天空大气组件的 Absorption 参数，用来加强落日的色彩、或改变暮色的调子。
Sky Atmosphere Overcast Luminance云量高时，按这个值缩放所有天空颜色的强度，让阴天整体压暗。

天空颜色：Simplified Color

Color Mode 为 Simplified Color 时，控制在 Simplified Color 分类里：

设置作用
颜色变量 控制天空的基础色，以及 2D 动态云和静态云的亮部、暗部颜色。体积云的颜色不在这里，在 Volumetric Clouds 分类。
Directional Intensity 曲线 平行光接近地平线时被压暗多少。
Directional Light Scattering 颜色曲线 平行光接近地平线时颜色如何被过滤。
太阳 / 月亮大气 LUT 体积纹理 天空材质据此结合相机方向与光线方向推导大气颜色。默认的 LUT 是经过复杂流程烘焙的，能贴近 Sky Atmosphere 的效果；需要改动时官方建议只对现成纹理做颜色变换，而不是重新制作。
