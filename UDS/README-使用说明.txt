Ultra Dynamic Sky 中文文档（离线网页版）
==========================================

【怎么打开】
双击 index.html，用 Chrome / Edge / Firefox 打开即可。
全部内容（含截图）都在本文件夹内，不联网也能看。

【两种主题】
左下角「纸张 / 石墨」切换：
· 纸张：暖白书页质感，适合长时间阅读、打印
· 石墨：中性深灰，夜间或强光下更舒适
选择会被记住。
