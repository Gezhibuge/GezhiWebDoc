光照与曝光

UDS 自带日月平行光与天光组件，并接管了云影、天光模式与自动曝光。这一页说明各组件的可控范围，以及用静态光照时需要注意什么。

组件而非 Actor曝光由 UDS 接管

灯光组件

UDS 内部自带三个灯光组件：代表太阳和月亮的两盏平行光，以及一盏天光（Sky Light）。 具体每个组件如何工作，由 太阳（Sun）、月亮（Moon）、天光（Sky Light） 三个分类里的设置决定； 天光还额外受 天光模式（Sky Light Mode） 影响。

也可以让 UDS 去引用关卡里现成的灯光 Actor，而不是用内置组件，但除非第三方资产或插件明确要求引用灯光 Actor，否则都不建议这么做。 如果确实要用，有两步必须手动补上：

  • 平行光：组件上有一个 云散射亮度缩放（Cloud Scattered Luminance Scale），控制灯光对云的影响。 这个值 UDS 没法通过蓝图写到你的灯光 Actor 上，需要自己从 UDS 的太阳或月亮组件上照抄过来。
  • 天光：天光组件上的 源类型（Source Type） 也无法被 UDS 控制，必须与 UDS 的 天光模式（Sky Light Mode） 对应： 使用 动态色调立方体贴图（Cubemap with Dynamic Color Tinting） 或 自定义立方体贴图（Custom Cubemap） 时，源类型要设为 指定立方体贴图（Specified Cubemap）；使用 基于捕获（Capture Based） 时设为 捕获场景（Captured Scene）。

日月平行光

太阳与月亮这两个平行光组件，有一部分属性由蓝图每帧驱动：颜色、强度、是否投射阴影、光源角度。 其余属性不会被每帧覆盖，可以直接在组件上改——选中 UDS 后，在细节面板顶部的组件列表里选 太阳（Sun） 或 月亮（Moon）， 看到的就是一个标准平行光组件的属性面板。

影响两者的公共参数在 平行光（Directional Light） 分类里；只影响其中一个的参数，则分别在 太阳（Sun）、月亮（Moon） 分类里。 日月的位置、运动与外观见 时间、日月与模拟。

云影

云影默认开启，并且与所有天空模式兼容，包括没有云的 无云（No Clouds）。 不需要的话可以在 云阴影（Cloud Shadows） 分类里关闭。

同一个分类里还能调：

  • 云量高/低时阴影的强度与柔和度。默认云量高时完全遮挡平行光，云量低时只部分遮挡。
  • 雾（Fog） 或 沙尘量（Dust Amount） 较高时，对平行光的遮挡比例。

天空模式为体积云时，云影按三维云层的实际形状计算，每一朵云都会在场景里投下对应的影子。 其他模式没有三维云层可投射，云影来自一张阴影贴图，其移动速度与尺度由 2D 云影速度（2D Cloud Shadows Speed） 与 2D 云阴影缩放（2D Cloud Shadows Scale） 控制。

天光（Sky Light）

天光模式（Sky Light Mode） 决定天光立方体贴图从哪来，以及 UDS 如何控制它的强度与颜色。

模式做法适用
基于捕获（Capture Based） 通过捕获天空生成立方体贴图。默认使用实时捕获，天光（Sky Light） 分类里可以开关。 画质优先，接受捕获开销
自定义立方体贴图（Custom Cubemap） 使用一张静态立方体贴图，在下方 天光立方体贴图（Sky Light Cubemap） 指定。 天空固定，或需要特定的环境光
动态色调立方体贴图（Cubemap with Dynamic Color Tinting） 用一张中性灰立方体贴图，按雾色动态染色，使环境光随昼夜变化。 动态昼夜项目，性能友好且全平台可用

天光颜色乘数（Sky Light Color Multiplier） 可以按时段分别给天光染色。这些乘数可以大于 1， 超过 1 时该时段的光照强度会按比例放大。

曝光

UDS 默认会应用自动曝光（Auto Exposure），引擎里也叫 Eye Adaptation。相关设置都在 曝光（Exposure） 分类里， 可以逐项调整，也可以关闭。

勾选 应用曝光设置（Apply Exposure Settings） 后，UDS 会接管以下几项：

引擎参数UDS 中的对应设置作用
Exposure Compensation Curve — 根据画面整体亮度把曝光往上或往下推。
Exposure Compensation 曝光偏移（Exposure Bias）（分时段、分天气） 可以单独把夜晚调亮、把阴天调暗。
Metering Mode 曝光测光模式（Exposure Metering Mode） 是否启用自动曝光以及用哪种测光方式。改成 手动（Manual） 会关闭自动曝光，但仍可使用曝光偏移。
MinEV100 / MaxEV100 曝光亮度范围（Exposure Brightness Range） 自动曝光试图适应的亮度区间。

如果曝光调不准，可以在视口里打开 显示 → 可视化 → HDR 人眼适应（Show → Visualize → HDR (Eye Adaptation)）， 直接看到自动曝光当前算出的数值，再对照后处理体积或相机里的曝光设置一起调。

使用静态 / 固定光照

UDS 默认全部使用可移动（Movable）光源，但也支持静态光照。要改成静态或固定（Stationary）， 请到 UDS 细节面板里对应的分类（太阳（Sun）、月亮（Moon）、天光（Sky Light））中找到 Mobility 设置， 改这一项即可，不要直接改灯光组件上的 Mobility。

构建光照之后，仍可以调整部分天空设置，但任何改动光源属性或位置的设置都会让已构建的光照失效，需要重新构建。 另外，太阳如果设为静态或固定，运行时 时刻（Time of Day） 就无法变化了。
