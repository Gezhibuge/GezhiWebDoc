Unreal Engine 5 · 蓝图叙事框架

Story Framework
中文说明书

如果你正在用 UE5 做一款「有剧情」的游戏——能捡东西、能翻笔记、能和 NPC 对话、能做选择、能存档—— Story Framework（简称 SF）就是把这些系统一次性做好的蓝图模板。 这套中文文档把作者那份英文官方文档重新排序、补充解释、按新手视角重写， 目标是让你不用啃英文也能把它用起来。

适用于 SF 5.0 – 5.2 UE 5.1 – 5.6（5.7 亦已支持） 纯蓝图 · 无需写 C++ 非官方中文版
先跑起来（10 分钟）→ 我想先懂原理 直接查速查表

这到底是什么东西？

Story Framework 是 Fab（虚幻商城）上的一个蓝图内容包，作者是 VisualOne Projects（社区里叫 Ctrl）。 它不提供模型、不提供动画、也不做战斗系统；它提供的是一整套「叙事游戏的地基」： 玩家怎么和世界互动、东西怎么进背包、剧情怎么推进、对话怎么分支、进度怎么保存。

用一个更好懂的说法：

虚幻引擎给了你「怎么做一个游戏」的全部零件，但没告诉你「叙事游戏该怎么搭」。 SF 就是别人已经搭好的那套骨架——你可以直接把家具搬进去，而不用先从打地基开始。

它最典型的使用场景，是做这类游戏：

第一/第三人称探索 点击式冒险（Point & Click） 解谜 + 拾取 + 组合道具 步行模拟 / 叙事驱动 恐怖探索（笔记、日记、回忆） 剧情向 RPG 的对话与任务层
给完全新手的定位

你可以把它理解成「一个已经写好剧本结构的样板房」：门能开、抽屉能拉、纸条能读、NPC 能聊。 你要做的是换掉里面的美术、改写台词、加几个自己的房间，而不是重新发明门轴。 因此它不能帮你做战斗、载具、联网对战——那部分仍然要你自己来（或另找插件）。

用 5.6 打开旧版本资产时

Fab 上买到的工程可能是按 5.4 / 5.5 保存的。用 5.6 打开时会提示「转换为新版本」——这是正常流程，点确认即可， 但请先备份整个工程文件夹。转换后资产会被重新保存，无法再退回旧引擎打开。 如果 Fab 提供了多个引擎版本的下载，优先选最接近 5.6 的那份。

三条阅读路线，别从第一篇硬啃

官方文档是按「功能模块」排列的，对新手并不友好——它先讲核心组件，最后才讲怎么把框架装进你自己的项目， 而且大量细节藏在 YouTube 视频里。这里改成了按你的目标来组织：

01 路线 A：我只想先看看它能干什么（约 30 分钟） 打开示例工程 → 玩一遍示例地图 → 改一个可交互物体。不求甚解，先建立手感。 → 02 路线 B：我要把它用在自己项目里（约 2 小时） 先懂「五大管理器 + 引用」这套骨架，再看交互、背包、对话三章，最后做迁移集成。 → 03 路线 C：我已经在做了，只想查东西 直接跳到速查表：资产路径、节点名、数据表、术语中英对照、视频清单。 →

五大系统：SF 的全部家当

SF 的所有功能，最终都收在五个挂在玩家身上的组件（Actor Component）里。 理解这一点，你就能理解整个框架为什么这么设计——也就能在需要的时候快速找到「该改哪里」。

Interaction
交互系统
玩家看向物体、出现提示、按键触发。5 种交互方式覆盖拾取、检视、开锁、拖动。
Inventory
背包与叙事容器
快捷背包、道具组合、日志、回忆录、主线/支线任务，全在这一个组件里。
Dialogue & Sequence
对话与过场
数据表驱动的分支对话、字幕语音、故事选择（Story Choice）、关卡序列播放。
UI
界面与输入提示
统一菜单容器（UMC）、手柄/键鼠自适应按键提示、弹窗通知。
Camera & World
相机与场景触发器
第一/第三人称一键切换、镜头函数、走进区域自动触发剧情。
Save
存档系统
保存/自动保存/读档三件套，支持跨关卡与自定义变量扩展。

本手册的读法约定

  • 文中出现的灰底提示块分几类：背景知识、经验技巧、易错点、第三方补充、给纯新手的解释，看左上角的小标题即可分辨。
  • 所有蓝图节点、资产名、变量名保留英文原样（写成 Add Main Task to Queue 这种），因为你在引擎里看到的就是英文。首次出现时会给中文解释。
  • “组件”指 Actor Component，“管理器”是社区里对五大组件的统称，不是引擎术语。
  • 标注“社区教程”的内容来自第三方资料（主要是 Jay Versluis 的 14 篇实战文章），并非官方原文。
关于这份文档的来源

正文主体翻译自官方文档（GitBook，共 36 页，约 1.3 万词），并按新手理解顺序重新编排； 官方只说「看视频」的部分（任务、对话、UMC 等），补入了社区教程里的具体节点名与操作步骤，并标注了出处。 官方文档本身仍在更新，若与你的版本有出入，以引擎里的实际资产为准。
