节点 / 函数速查

除了「引用」一栏，其余都需要先拿到对应管理器。

交互管理器

节点用途
Perform Action开始一段带进度条的动作
Stop Current Action中断当前动作
OnPerformActionFinished / OnPerformActionStopped动作结束 / 被打断的事件
Create Quick Time Event创建一次 QTE
Spawn Interactable Saved生成可交互物并立刻存入存档

背包管理器

节点用途
Add Item to Inventory加道具（可同时销毁地上的物体）
Remove Selected Item From Inventory删道具（可选掉到地上）
Find Item in Inventory by Name查某个道具的数量
DoItemsArrayExistInInventory批量检查是否齐全
EditItemInInventoryByName运行时修改道具数据
Add Journal Entry / Remove Journal Entry增删日志
Edit Consequential Tags增删剧情标记（回忆录 / 对话分支的总开关）
Add Main Task to Queue加主线任务
Complete Current Main Task完成当前主线
Edit Target Main Task in Queue修改进行中的任务
Find Task in Queue by Header按标题查任务
OnTaskInitialized任务初始化事件

节点所属用途

Lock Focus On Target相机管理器强制锁定视角
Look At Target Once相机管理器平滑看向某处
Play Level Sequence序列管理器播过场
Play Sound With Subtitles序列管理器声音 + 字幕
Create Story Choice序列管理器全屏二选一
Save Game / Auto-Save / Load Game存档管理器存 / 自动存 / 读

数据表存什么什么时候改

术语中英对照

英文本手册译法一句话说明
Interaction Method交互方式物体被交互时的行为类型，共 5 种
Primary / Secondary Interaction Method主 / 次交互方式PIM 五选一，SIM 只能 None 或 Inspect
Interactable可交互物继承 InteractableBase_BP 或实现交互接口的 Actor
Inspect检视把物体拿到镜头前查看
Quick-Inventory快捷背包底部工具栏式背包
Journal Entry日志条目记录“见过但没带走”的东西
Memoir回忆录玩家做过的关键决定的记录
Consequential Tag剧情标记全局的布尔记忆，驱动对话分支与回忆录
Task / Quest任务主线（Main）与支线（Side/Optional）
Sequence关卡序列过场动画
Subtitle字幕可独立使用的文本演出
Story Choice故事选择全屏二选一的重要抉择
Quick Time Event (QTE)快速反应事件限时按键
Unified Menu Container (UMC)统一菜单容器把背包/日志/任务收在一个界面
SFV (StoryFrameworkValues)框架设置资产全局配置数据资产
Actor ComponentActor 组件挂在 Actor 上的功能模块
Blueprint Interface (BPI)蓝图接口让不同类被统一调用的“函数名单”
Input Mapping Context (IMC)输入映射上下文一套按键方案，按场景切换
Data Table / Data Asset数据表 / 数据资产把数据从蓝图里分离出来的资产
Event Dispatcher事件分发器广播机制，用于解耦
Soft Lock软锁 / 卡关玩家陷入无法继续的状态（设计失误）
