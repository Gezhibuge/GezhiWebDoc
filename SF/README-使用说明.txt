Story Framework 5.2 中文文档 · 使用说明
========================================

打开方式
--------
双击本文件夹里的 index.html，用浏览器打开即可。无需服务器、无需联网（YouTube 视频需要网络）。

内容
----
- 完整对应官方 GitBook 的 36 个页面，章节顺序与官方一致。
- 67 张官方截图全部下载到 assets/img/，点击图片可放大查看。
- 6 个官方 YouTube 教程以嵌入方式保留；文末附“在 YouTube 打开”链接。
- 所有 UE 蓝图节点、函数、事件与变量类型均写成 `中文(English)` 行内代码，例如 `事件开始运行(Event BeginPlay)`。
- 在相关章节末尾，以“补充说明 · 非官方”方块整合了 Jay Versluis 的实践文章；来源链接一并保留。

功能
----
- 左侧目录：按官方五大章节分组；移动端点击左上角菜单按钮打开抽屉。
- 搜索：点击右上角“搜索文档”，或按 Ctrl + K / Cmd + K；支持中文与英文关键词。
- 主题：右上角切换“纸张浅色”与“深色（原版）”；选择会保存在浏览器本地。
- 本页目录：长页面右侧会显示小节导航；没有小节标题的页面会自动隐藏该栏。
- 图片灯箱：点击正文截图放大，Esc 或点击空白处关闭。
- 键盘：Esc 关闭搜索/灯箱/移动端目录。
