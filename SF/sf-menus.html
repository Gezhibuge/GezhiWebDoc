SF 菜单

什么是 SF 菜单？

SF 菜单是为更“通用”的菜单而创建的控件，例如主菜单、暂停菜单等。这些菜单与框架中其他的 UI 覆盖层和菜单是分开的。

为什么需要它？

SF 是一个对输入方式友好的框架，也就是说 UI 应该兼容任何输入类型：鼠标键盘或手柄。这些“SF 菜单”提供了一套同时支持鼠标、键盘与手柄输入的工作流。

框架中的其他菜单和 UI 则被设计为只通过输入控制。例如导航时，滚轮(Scroll-Wheel) 相当于键盘上的上/下，方向键上/下(D-Pad Up/Down) 对游戏手柄做同样的事。

这是 SF 对控件导航的自定义解决方案。

通用准则

下面是在使用“SF 菜单”工作流创建自己的菜单时，应遵循的一些通用规则：

  • 按钮必须使用 MenuButton_W 类。
  • 菜单应使用 创建/移除 SF 菜单(Create/Remove SF Menu) 函数来创建和移除。
  • 按钮导航应在每个按钮的导航选项（细节面板）中手动设置。
  • 视口中同一时间只应存在一个 MenuMaster_W 控件蓝图。

想进一步了解如何设置这些“SF 菜单”，请观看下文链接的教程。
